# 🎒 Marlons Schultag

Ein Lernspiel zum Üben von Maus- und Tastaturbedienung – Thema Schule.
Gemacht für ein 7-jähriges, hyperaktives Kind. Ohne Zeitdruck, ohne
Verlieren, ohne Frustration.

## Spielen

1. [`marlons-schultag.html`](./marlons-schultag.html) herunterladen
   (auf GitHub: Datei öffnen → **Download raw file**, oder das ganze Repo
   klonen/herunterladen).
2. Datei per Doppelklick öffnen – sie läuft direkt im Browser, komplett
   offline. Kein Internet, keine Installation, kein Server nötig.

## Was steckt drin?

- **12 Missionen** in 6 Welten rund um den Schulalltag:
  - ✏️ **Klassenzimmer-Klick** – mit der Maus anklicken (inkl. Doppelklick üben!)
  - 🎒 **Ranzen packen** – Drag & Drop
  - 🚸 **Schulweg** – Pfeiltasten
  - 🤸 **Pausenhof** – Leertaste im richtigen Moment (Seilspringen, Ball fangen)
  - 🖊️ **Tafelbild** – Maus bewegen (ohne Klicken)
  - 📝 **Diktat** – Namen und Zahlen tippen
- **Freie Missionsauswahl**, **Schwierigkeitsgrad** (Leicht 🐣 / Mittel 🚀 /
  Profi 🌟) und **kein Fail-State** – wie bei allen Spielen aus dieser Reihe.

## Technik

Eine einzelne HTML-Datei mit eingebettetem CSS und Vanilla-JavaScript,
keine externen Abhängigkeiten, keine Build-Tools. Läuft in jedem
aktuellen Browser auf einem normalen Windows-Laptop.

Nutzt dieselbe Spiel-Engine wie [Marlons Sternenreise](../marlons-sternenreise/),
nur mit Schul-Thema statt Weltraum-Thema.
