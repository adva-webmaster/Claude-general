# 🚀 Marlons Sternenreise

Ein Weltraum-Lernspiel zum spielerischen Üben von Maus- und Tastaturbedienung –
gemacht für ein 7-jähriges, hyperaktives Kind. Ohne Zeitdruck, ohne
Verlieren, ohne Frustration.

## Spielen

1. [`marlons-sternenreise.html`](./marlons-sternenreise.html) herunterladen
   (auf GitHub: Datei öffnen → **Download raw file**, oder das ganze Repo
   klonen/herunterladen).
2. Datei per Doppelklick öffnen – sie läuft direkt im Browser, komplett
   offline. Kein Internet, keine Installation, kein Server nötig.

## Was steckt drin?

- **30 Missionen** in 6 thematischen Welten, jeweils 30–60 Sekunden lang.
  Jede der 5 Missionen einer Welt nutzt eine eigene Spielmechanik statt nur
  andere Zahlen – z.B. bei den Klick-Missionen: Ziele einzeln anklicken,
  in Reihenfolge, Störer meiden, bewegliche Ziele treffen, oder eine
  Kombination davon:
  - ⭐ **Sternen-Klick** – mit der Maus anklicken
  - 📦 **Fracht-Andocken** – Drag & Drop
  - 🚀 **Raketen-Steuerung** – Pfeiltasten
  - ☄️ **Asteroiden-Sprung** – Leertaste im richtigen Moment
  - 💫 **Sternenstaub** – Maus bewegen (ohne Klicken)
  - 🔤 **Funksprüche** – den eigenen Namen und Weltraum-Wörter tippen
- **Freie Missionsauswahl**: Die erste Mission jeder Welt ist von Anfang an
  offen, bereits geschaffte Missionen lassen sich jederzeit wiederholen.
- **Schwierigkeitsgrad wählbar**: Leicht 🐣 / Mittel 🚀 / Profi 🌟 – wirkt
  sich auf Tempo, Zielzahlen und Trefferzonen aus, aber nie auf ein
  Fail-State: Verlieren gibt es nicht.
- **Kein Zeitdruck**, respektiert `prefers-reduced-motion`, funktioniert
  komplett offline (kein Server, kein LocalStorage, kein Backend).

## Technik

Eine einzelne HTML-Datei mit eingebettetem CSS und Vanilla-JavaScript,
keine externen Abhängigkeiten, keine Build-Tools. Läuft in jedem
aktuellen Browser auf einem normalen Windows-Laptop.
